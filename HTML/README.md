
# TechDesk | Estrutura e Estilização

Esta pasta reúne os arquivos HTML e CSS utilizados
no desenvolvimento do TechDesk.

Aqui estão organizados os códigos responsáveis pela
estrutura das páginas e pela parte visual do sistema.

## Sobre os arquivos

- **HTML:** responsável pela estrutura e organização
dos elementos presentes nas páginas.

## Desenvolvimento

Os arquivos serão atualizados conforme novas páginas,
componentes e funcionalidades forem adicionados ao projeto.

O objetivo é manter o código organizado e registrar
a evolução do TechDesk durante seu desenvolvimento.

**Status:** Em desenvolvimento.
